# CLOSET MIX V1

GitHub Pagesで動く、ブランド横断デジタルクローゼットの試作版です。

## ファイル
- index.html
- manifest.webmanifest
- sw.js
- icon.svg

## 公開
4ファイルをリポジトリ直下にアップロードし、GitHub Pagesを有効にしてください。

## V1
- iPhoneカメラから服・タグ写真を登録
- ブランド、カテゴリ、色、サイズ、価格、品番/JANを保存
- 「試着候補」「購入済み」を区別
- 当日の候補金額を集計
- ブランド横断の簡易コーデ作成
- localStorage保存
- ホーム画面追加対応

## 次の段階
AI画像認識、OCR、JAN/GTIN検索、バーコードカメラ読み取り、AIコーデ評価をAPI経由で追加予定。
